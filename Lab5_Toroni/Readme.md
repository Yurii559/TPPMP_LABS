## Детальний розбір реалізації

### Завдання №1 — Факторіал числа

Функція `factorial(_ n: Int) -> Int?` обчислює факторіал цілого числа без використання сторонніх чи вбудованих математичних функцій.

* **Валідація:** через `guard n >= 0` відсіюються від'ємні числа (функція повертає `nil`).
* **Базовий випадок:** для 0! та 1! одразу повертається `1`.
* **Ітеративний розрахунок:** цикл `for i in 2...n` послідовно перемножує числа від `2` до `n`.

```swift
func factorial(_ n: Int) -> Int? {
    guard n >= 0 else { return nil }
    if n <= 1 { return 1 }

    var result = 1
    for i in 2...n {
        result *= i
    }
    return result
}
```

### Завдання №2 — Сортування масиву

Функція `sortArray(_ array: [Int], algorithm: SortAlgorithm = .bubble) -> [Int]` сортує переданий масив без використання вбудованих методів `sort()` або `swapAt()`.

* **Вибір алгоритму:** реалізовано перерахування `SortAlgorithm` (`bubble` і `selection`). За замовчуванням використовується сортування бульбашкою.
* **Бульбашкове сортування (Bubble Sort):** оптимізоване прапорцем `swapped` — якщо за весь прохід не відбулося жодного обміну, цикл достроково завершується через `break`.
* **Сортування вибором (Selection Sort):** на кожній ітерації знаходить індекс мінімального елемента в невідсортованій частині та міняє його місцями з поточним елементом через тимчасову змінну `temp`.

### Завдання №3 — Аналізатор символа

Функція `analyzeCharacter(_ char: Character)` визначає тип символа, абетку (англійська чи українська) та регістр, виводить зрозумілий результат у консоль і повертає кортеж `(category, alphabet, letterCase)`.

* Атрибут `@discardableResult` дозволяє викликати функцію заради виводу в консоль без попередження компілятора про невикористане повернене значення.
* Конструкція `switch` поєднує перевірку діапазонів (`"0"..."9"`, `"A"..."Z"`, `"a"..."z"`) із додатковими умовами `where` для українських літер.

```swift
switch char {
case "0"..."9":
    category = "Цифра"
case "A"..."Z":
    category = "Літера"; alphabet = "Англійська"; letterCase = "Великий регістр"
case let c where ukrUpper.contains(c):
    category = "Літера"; alphabet = "Українська"; letterCase = "Великий регістр"
// ...
}
```

### Завдання №4 — Аналізатор рядка

Функція `analyzeString(_ text: String) -> [Character: Int]` підраховує кількість входжень кожного символа у вхідному рядку та формує частотну таблицю.

* Використано синтаксис `counts[char, default: 0] += 1`, який лаконічно збільшує лічильник для наявного символа або створює новий запис із початковим значенням `0`.

### Завдання №5 — Функція-калькулятор

Реалізація розділена на два незалежні рівні відповідно до вимог завдання:

1. **Меню вибору операції** `chooseOperation(_ symbol: String) -> MathOperation?` — містить вкладені функції (`add`, `subtract`, `multiply`, `remainder`, `power`) і повертає потрібну функцію за її символом, **не викликаючи** основний калькулятор.
2. **Основна функція-калькулятор** `calculate(_ a: Int, _ b: Int, operation: MathOperation) -> Int?` — приймає два операнди та функцію-операцію і повертає результат її виконання.

**Особливості реалізації операцій:**
* Остача від ділення (`%`) захищена від ділення на нуль (`guard b != 0 else { return nil }`).
* Піднесення до степеня (`^`) реалізоване циклом без використання вбудованої функції `pow()`.
* Користувач вводить лише два вхідних числа (передбачені значення за замовчуванням `5` та `3`), після чого всі 5 операцій виконуються послідовно.

### Завдання №6 — Належність точки колу

Функція `findLargestContainingCircle(circles: [Circle], point: Point) -> Circle?` знаходить коло з найбільшим радіусом, усередині якого (або на межі якого) лежить задана точка.

* **Без класів і структур:** відповідно до обмежень завдання, геометричні сутності описані через іменовані кортежі та `typealias`:
  ```swift
  typealias Point = (x: Double, y: Double)
  typealias Circle = (center: Point, radius: Double)
  ```
* **Перевірка належності:** замість обчислення квадратного кореня порівнюються квадрати відстані та радіуса, що точніше та швидше:
  $$(x - x_0)^2 + (y - y_0)^2 \le r^2$$
* Кола з від'ємним радіусом пропускаються за допомогою `guard circle.radius >= 0 else { continue }`.
