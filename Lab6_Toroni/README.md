## Детальний розбір реалізації

### Завдання №1 — Геометричний примітив «Точка»

Реалізовано три взаємопов'язані структури: `CartesianPoint`, `PolarPoint` та основну структуру `Point`, яка автоматично синхронізує декартові та полярні координати.

* **Контроль доступу та значення за замовчуванням:** усі координатні властивості мають модифікатор `private(set)`, що дозволяє зчитувати їх ззовні, але забороняє змінювати напряму поза межами структури.
* **Синхронізація систем координат:** при створенні точки через (x; y) полярні координати обчислюються автоматично (і навпаки). Для точного визначення кута у всіх чотирьох квадрантах використано `atan2(y, x)`.
* **Зміщення точки:** методи `move(toX:y:)` та `move(toRadius:angle:)` позначені як `mutating`, оскільки структури в Swift є типами значень (*Value Types*).
* **Рядкове представлення:** метод `description(in:)` приймає `CoordinateSystem` (за замовчуванням `.cartesian`) та форматує координати у зручний вигляд.
* **Розширення (`extension Point`):**
  * обчислення відстані між двома точками (`static func distance(from:to:)`);
  * додаткові ініціалізатори для користувацьких типів `CartesianCoordinates` та `PolarCoordinates` із делегуванням через методи `move`;
  * чотири фабричні методи типу `makePoint(...)` для створення точок різними способами.

```swift
var p1 = Point(x: 3, y: 4)
print(p1.description())             // Cartesian(x: 3.00, y: 4.00)
print(p1.description(in: .polar))   // Polar(radius: 5.00, angle: 0.93 rad)

p1.move(toRadius: 10, angle: .pi / 2)
let p2 = Point.makePoint(cartesian: CartesianCoordinates(x: 0, y: 0))
let p3 = Point.makePoint(polar: PolarCoordinates(radius: 5, angle: 0))
let dist = Point.distance(from: p2, to: p3) // 5.0
```

### Завдання №2 — Геометричний примітив «Фігура»

Структура `Shape` описує довільну геометричну фігуру на основі масиву точок `Point`.

* **Захист даних:** масив `points` та тип фігури `type` закриті для зовнішньої зміни за допомогою `private(set)`.
* **Автоматичне визначення типу (`ShapeType`):** під час створення фігури її тип визначається автоматично за кількістю вершин (`unknown`, `point`, `line`, `triangle`, `quadrilateral`, `polygon`).
* **Гнучка ініціалізація:** підтримується створення фігури як із готового масиву `[Point]`, так і з довільного ряду точок (`Point...`) через делегування ініціалізатора.
* **Безпечний індексатор (`subscript`):** повертає опціонал `Point?`, що запобігає аварійному завершенню програми при виході за межі масиву.
* **Розширення (`extension Shape`):** містить статичні функції `perimeter(of:)` і `area(of:)`, а також відповідні обчислювані властивості екземпляра `perimeter` та `area`.

```swift
let triangle = Shape(
    points: Point(x: 0, y: 0),
    Point(x: 3, y: 0),
    Point(x: 0, y: 4)
)
print(triangle.type.rawValue) // Трикутник
print(triangle.perimeter)     // 12.0
print(triangle.area)          // 6.0
```
